# Capturas de portafolio

Generá el set con `npm run screenshots`. El script usa Playwright contra Vite en modo desarrollo (no ejecuta build), reemplaza las URLs de Sheets por endpoints ficticios interceptados y usa datos demostrativos; no consulta ni muestra los datos reales de la hoja. Escribe PNGs en esta carpeta.

Capturas: hero y página completa en desktop; inventario, detalle de medicamento e insumos en desktop; hero, página completa, medicamentos, insumos y búsqueda vacía a 375 × 812 px.
